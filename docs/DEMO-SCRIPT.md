# Demo video script (under 3 minutes)

Record in desktop Chrome at https://offline-hybrid-ai.web.app. Use a 1280×800 window, or Chrome DevTools' device mode at 430×880 for a phone look. English voice-over, with captions from the script below.

**Before recording:**
- Open the app once while online, so it's installed in the browser cache.
- Tap the status chip and check **On-device AI**.
  - If it says *Ready*, the on-device shots work as written.
  - If it says *Downloadable*, tap **Download model** the day before.
  - If it says *Unavailable*, keep the shots and say "on a supported device this runs locally". The labels will show *Cloud*, which is honest.

| Time | On screen | Voice-over |
| --- | --- | --- |
| 0:00–0:12 | The site hero; the phone loop plays | "Voice is the fastest way to prompt AI. But sometimes you can't talk out loud, or you have no signal. Offline is for those moments." |
| 0:12–0:25 | Click **Open Offline**. Tap the status chip; scroll *What works right now*. | "It tells you honestly what works on *this* device right now: recording, on-device AI, the cloud." |
| 0:25–0:50 | Menu → **Work offline**. Tap the mic: the recording screen pours out of the button (the genie). Speak a messy thought: "okay so tell the team we're pushing the launch a week because QA found two checkout bugs, keep it calm". Tap **Save**. | "One tap. It's recording, and saving on the device as I speak. No network at all." |
| 0:50–1:10 | Draft: "Saved on this device, not sent". Turn **Work offline** off: the banner says nothing has been sent. Tap **Transcribe with Gemini**. Open the sentences; tap one and it plays. | "Back online, nothing was sent by itself. I choose to transcribe. Each sentence plays its own moment." |
| 1:10–1:40 | **Improve → Make it clearer** (route label *This device* or *Cloud*). Open **Versions → Compare**. **Ask me what's missing**; answer one question. Pick the **Email** template and **Friendly**. | "Shaping runs on Gemini Nano when Chrome has it. Every rewrite is a version; my original is kept." |
| 1:40–2:05 | **Run with AI**: the preview shows the exact text and the destination. **Send**. The answer streams with its label. | "Before anything leaves, I see the exact text and where it will run. Every answer says where it was made." |
| 2:05–2:25 | Open a long **Note** → menu → **Keep on this device only** → **Summarize** (on-device in parts, or blocked with a reason). | "Anything can be kept on the device only, and Offline respects that: it never quietly reaches the cloud." |
| 2:25–2:45 | Menu → **History**: mode asked, where it ran, model, seconds. | "History records every request: what we asked for, where it actually ran, and how long it took." |
| 2:45–3:00 | The README's routing table, or the site's *One call, two places to run* section; the URL and repo. | "Built on Firebase AI Logic hybrid inference, with App Check and Remote Config. Offline: say it now, send it when you choose." |
