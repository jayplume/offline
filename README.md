# Offline

Say it now. Send it when you choose.

Offline is a private voice-to-AI app built for the [#BuildHybridAI 2026](https://firebasehybridaihackathon.devpost.com/) hackathon on **Firebase AI Logic hybrid inference**. It records spoken prompts anywhere, even with no signal, keeps them on the device, helps shape them (on-device with Gemini Nano in Chrome when available), and runs them with Gemini only when the person presses Send.
